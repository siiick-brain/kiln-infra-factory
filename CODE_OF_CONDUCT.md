# Code of conduct

## Expected behaviour

- Be respectful and assume good intent.
- Keep discussion technical and on topic.
- Review the work, not the person.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language and the publication of private information.

## Enforcement

The maintainer may edit or remove comments and block accounts that break these rules.
Report a problem through a private security advisory on the repository so the report stays private.
