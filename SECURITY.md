# Security policy

## Scope

This repository is a demonstration. Nothing in it is deployed to a real cloud account.
Keys, certificates and secrets in examples are fake or generated at run time outside the repository.

## Reporting a vulnerability

Open a private security advisory on the GitHub repository page under Security, then Report a vulnerability.
Do not open a public issue for a vulnerability.
Include the file, the command that shows the problem and the expected behaviour.

## Response

Reports are acknowledged within 7 days. A fix lands as a normal commit with a regression test.
There is no bounty.

## Supported versions

Only the `main` branch is maintained.
